更新方法：
- 先備份 GitHub 儲存庫目前版本。
- 解壓縮本 ZIP，進入 GitHub 儲存庫 xiangwan-ichiban。
- 將 index.html、bridge-client.js、assets/、.nojekyll 等原檔直接上傳到該儲存庫根目錄；同名檔案覆蓋。
- 等 GitHub Pages 自動重新部署，從手機重新整理查看。
- 不需修改 Google Apps Script，也不要重新建立試算表。
